CODECHECK — CODE ERROR DETECTOR
================================

PROJECT FILES
-------------
index.html       Main webpage
css/style.css    Website design and responsive layout
js/app.js        Code analysis and interface logic

HOW TO RUN
----------
1. Extract the CodeCheck folder if it is in a ZIP file.
2. Open the CodeCheck folder.
3. Double-click index.html to open the site in Chrome, Edge, or Firefox.
4. Choose a language, write/paste code, and click Analyze code.
5. Use Load sample to try an example.

NOTES
-----
This is a client-side prototype. JavaScript and JSON use browser parsing;
HTML/CSS and other language checks use lightweight static rules. It does
not run full compilers for Python, C, C++, Java, or Arduino/ESP32, and it
cannot guarantee finding every bug. Use official compilers/linters for
complete diagnostics.
